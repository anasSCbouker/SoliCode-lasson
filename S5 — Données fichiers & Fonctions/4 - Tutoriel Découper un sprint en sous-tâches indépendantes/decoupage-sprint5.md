# Sprint 5 Action Plan

## Global Sprint Mission

Create a modular PHP page that loads a list of articles stored in an array and displays them correctly on the home page.

## Ordered Subtasks

| Step | Action | Target File | Validation Condition |
|---|---|---|---|
| 1 | Create the PHP articles array | `data/articles.php` | The file contains an `$articles` array with three valid articles. |
| 2 | Create the article formatting function | `includes/functions.php` | The function receives one article and returns clean HTML. |
| 3 | Load the data and display the articles with a loop | `index.php` | The `foreach` loop reads the articles without PHP syntax errors. |
| 4 | Test the final result in the browser | Web browser | The three articles appear with their titles and summaries without PHP errors. |

## Final Verification

The last step is dedicated to testing and validating the final result in the browser.
