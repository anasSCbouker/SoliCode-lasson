SoliCode Log - Original Design Learning Copy

This project preserves the HTML layouts and CSS of the supplied complete SoliCode Log website.
It is an interface-only learning copy, not a live attendance or administration service.

Run:
  cd SoliCode_Log
  php -S localhost:8000

Open:
  http://localhost:8000/index.php

Main lessons:
  index.php: a PHP array and require
  index-template.php: HTML and a foreach loop with htmlspecialchars
  gate.php: a simple if / else condition

Other original page routes remain as static previews.
Unfinished operations show: Coming soon - In progress as I learn.

No original database, private user uploads, login sessions, mail settings,
secret keys, student records, or real administrative operations are included.

Useful page previews:
  /admin/dashboard.php
  /student/dashboard.php
  /teacher/dashboard.php
  /guard/dashboard.php
  /login.php

The original global stylesheet is preserved with only Arabic comments removed.
