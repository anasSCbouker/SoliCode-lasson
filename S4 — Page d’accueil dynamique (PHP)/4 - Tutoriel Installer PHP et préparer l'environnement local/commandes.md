# PHP Local Server

## 1. Check PHP

```bash
php -v
```

This command shows the PHP version.

## 2. Start the server

Open the folder with `test-serveur.php`, then run:

```bash
php -S localhost:8000
```

## 3. Open the page

Open this address in your browser:

http://localhost:8000/test-serveur.php

Expected text: `PHP local server is working`

## 4. Stop the server

Press `Ctrl + C` in the terminal.
