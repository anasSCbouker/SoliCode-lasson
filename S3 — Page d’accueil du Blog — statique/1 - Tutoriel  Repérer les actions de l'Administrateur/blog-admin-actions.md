# Admin Actions – Blog

## Goal
Find all actions of the Admin in the Blog admin area.

## 1. Dashboard

Actions found:

- Click "Manage articles".
- Click "Manage categories".
- Click "Log out".

## 2. Articles page

Actions found:

- See the article list.
- Click "Add article".
- Click "Edit" icon on a line.
- Click "Delete" icon on a line.

## 3. Article form

Actions found:

- Fill the form: Title, Image, Category, Content.
- Click "Save".

## 4. Categories pages

Actions found:

- See the category list.
- Add a category. Fill the form. Save.
- Edit a category.
- Delete a category.

## 5. CRUD check

The Admin actions follow CRUD:

| Letter | Action | Simple meaning | Example |
|---|---|---|---|
| C | Create | Add new data | Add article |
| R | Read | See data list | See articles |
| U | Update | Change data | Edit article |
| D | Delete | Remove data | Delete article |

Same CRUD for Articles and Categories.

## 6. Entities

Entities managed by Admin:

- **Article**: content in the Blog.
- **Category**: group of articles.

## Result
The Admin can manage Articles and Categories.

The Admin can:

- See lists.
- Add new data.
- Edit data.
- Delete data.

All actions follow the CRUD model.
