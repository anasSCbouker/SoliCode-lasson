# Visitor Functional Synthesis Table

---

## Functional Synthesis — Actor: Visitor

| Actor | Functionality | Functional Path (Start → Action → Result) |
|-------|--------------|-------------------------------------------|
| Visitor | View the list of articles | Home page → Click "Lire les articles" → See all recent articles |
| Visitor | Filter articles by category | Home page → Click a category filter → See filtered articles |
| Visitor | View all articles | Home page → Click "Explorer tout" → Go to category page with all articles |
| Visitor | Read an article | Home page → Click on article title image → See full article details |
| Visitor | Navigate between articles | Article page → Click "Précédent" or "Suivant" → See previous or next article |
| Visitor | View articles by category | Category page → Click a category filter → See articles of that category |
| Visitor | Read article from category page | Category page → Click article title → See full article |
| Visitor | View the About page | Any page → Click "À Propos" → See author info and skills |
| Visitor | Follow author on social media | About page → Click social media link → Open social profile |
| Visitor | Go to admin login page | Any page → Click "Espace Admin" → See admin login form |
| Visitor | Try to login as admin | Admin login page → Fill email and password → Click "Se connecter" → Enter admin panel or see error |
| Visitor | Return to site from login page | Admin login page → Click "Retour au site" → Go back to home page |
| Visitor | View legal information | Any page → Click "Mentions légales" in footer → See legal notices |
| Visitor | View privacy policy | Any page → Click "Politique de confidentialité" → See privacy policy |
| Visitor | Return to home page | Any page → Click logo "MonBlog" → Go to home page |
