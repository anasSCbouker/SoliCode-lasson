# Save Code with VS Code

## Steps Done

1. **Create Repo**: Made a new repo on GitHub. Copied the URL.
2. **Clone**: Opened VS Code. Clicked Clone. Pasted URL. Opened the folder.
3. **Modify**: Changed `index.html`. Saved the file.
4. **Stage (+)**: Opened Source Control tab. Clicked `+` on the file.
5. **Commit**: Wrote a message: "Add main title". Clicked Commit.
6. **Sync**: Clicked Sync Changes. Sent code to GitHub.

## Result

The changes are now visible on the GitHub website.
