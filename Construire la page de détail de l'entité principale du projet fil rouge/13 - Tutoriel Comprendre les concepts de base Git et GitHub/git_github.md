# Git vs GitHub Exercise

## Part 1: Match the Action to the Tool

| Action | Tool |
|---|---|
| Save a commit on your computer | Git |
| View a friend's project online | GitHub |
| Make project history without internet | Git |
| Send your code to share online | GitHub |

## Part 2: Key Concepts

- **Git**: A tool on your computer. It saves your work. It works without internet.
- **GitHub**: A website online. It stores your Git projects. It needs internet.
- **Local Repository**: Your project folder on your computer. Git manages it.
- **Remote Repository**: Your project copy on GitHub server.
- **git push**: Send your work from your computer to GitHub.
- **git pull**: Get work from GitHub to your computer.
